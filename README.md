# Filesfm MacOS

## How do I install these casks?

`brew install --cask filesfm/macos/<cask>`

Or `brew tap filesfm/macos` and then `brew install --cask <cask>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "filesfm/macos"
cask "<cask>"
```

## Available casks

- `worktime`: [WorkTime](https://github.com/filesfm/WorkTime), a Qt6/QML desktop time tracker
- `files-fm-sync`: [Files.fm Sync](https://github.com/filesfm/Sync), a desktop client that keeps local folders synchronized with your Files.fm account
